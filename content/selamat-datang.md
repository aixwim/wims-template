Ini adalah halaman contoh dari template jaringan **Wim**.

Template ini dibangun dengan **Next.js** (static export) dan sudah siap dipakai:

1. Salin repo template ke repo situsmu.
2. Isi `site.config.json` (repo, brand, tagline, dll).
3. Tambahkan artikel Markdown di folder `content/`.
4. Jalankan `npm run assets` untuk generate `og.png` dan favicon sesuai brand.
5. Build dan deploy ke GitHub Pages.

Hapus file ini saat kontenmu sudah siap.
